## A bit about me

I'm finishing my BS in Computer Science, majoring in Intelligent Systems, and most of what I know I've learned by building things people actually needed — not just assignments. My thesis, **OSCA-AgeSense**, is a machine learning tool I'm building with the Pagsanjan, Laguna OSCA office to help assess health risk in senior citizens, grounded in WHO's Healthy Ageing framework. It's the project that's taught me the most, because the stakes weren't hypothetical.

I care about four things, roughly in this order: **data analysis, web development, project management, and AI/ML.** I don't treat them as separate lanes — a good data pipeline needs to be shipped as working software, and working software needs someone keeping the project honest about scope and deadlines. That's the kind of developer I'm trying to become.

Earlier this year, my team and I placed **Top 3 at Hack4AProgress 2026** (DOST CALABARZON) with *AgriWise*, built with Team EverForge at LSPU – Santa Cruz Campus. It was the first time I saw an idea go from a whiteboard to something judges cared about in under 48 hours, and I've been chasing that feeling since.

- 🎓 Wrapping up my degree while building OSCA-AgeSense as my thesis
- 🧩 Also behind a few other real projects: **PropertyAI** (a hybrid ML + knowledge-representation housing recommender), a full-stack **management system for Santa Cruz Bible Christian Church**, and **Findify**, an e-commerce app I built for both web and mobile
- 💼 Freelancing on the side — mostly data cleaning and statistics for other students' theses
- 📫 Best way to reach me: [jezreelramoz@gmail.com](mailto:jezreelramoz@gmail.com)
